# 修改utils/analyze_similarity_diff.py文件的导入路径

## 问题分析

当前运行脚本时出现 `ModuleNotFoundError: No module named 'config'` 错误，这是因为：
- 当从utils目录运行脚本时，Python的搜索路径不包含项目根目录
- 脚本直接尝试导入 `from config import config`，但无法找到config模块

## 解决方案

在脚本开头添加代码，将项目根目录添加到Python的搜索路径中，这样就可以正确导入config模块了。

## 实施步骤

1. **修改导入部分**：
   - 在文件开头添加sys模块导入
   - 添加代码获取项目根目录并添加到sys.path
   - 保持原有的config模块导入

2. **具体修改内容**：
   - 在第1行添加 `import sys`
   - 在第2行添加 `from pathlib import Path`
   - 在第3行添加代码：
     ```python
     # 获取项目根目录并添加到搜索路径
     root_dir = Path(__file__).parent.parent
     sys.path.insert(0, str(root_dir))
     ```
   - 保持后续的导入语句不变

3. **验证修改**：
   - 运行修改后的脚本，确保能够正确导入config模块
   - 确保脚本能够正常执行分析功能

这样修改后，无论从哪个目录运行脚本，都能够正确找到并导入config模块。
