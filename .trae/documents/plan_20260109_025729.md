# 修复钢轨探伤B显数据可视化工具的问题

## 问题分析
当前程序中，用户进行放大或缩放操作后，单击点击会导致视图自动恢复到原始缩放状态。这是因为每次点击事件都会触发`update_bscan`方法，该方法会重新设置坐标轴的限制，从而导致缩放状态丢失。

## 修复计划

### 1. 添加自动缩放恢复控制标志
   - 在`BScanCanvas`类的`__init__`方法中添加一个新的属性`self.auto_reset_zoom`，默认值为`True`
   - 用于控制是否在更新B显图像时自动恢复缩放状态

### 2. 修改坐标轴限制设置逻辑
   - 修改`BScanCanvas`类的`update_bscan`方法，添加对`self.auto_reset_zoom`的检查
   - 只有当`self.auto_reset_zoom`为`True`时，才重新设置坐标轴的限制
   - 当`self.auto_reset_zoom`为`False`时，保持当前的坐标轴限制不变

### 3. 添加GUI开关控件
   - 在`create_combined_display`方法中添加一个`QCheckBox`开关控件，用于控制自动缩放恢复功能
   - 设置默认状态为选中（即开启自动缩放恢复）
   - 连接开关控件的状态变化信号到对应的处理方法

### 4. 实现开关状态处理方法
   - 在`MainWindow`类中添加`on_auto_reset_zoom_changed`方法
   - 该方法接收开关状态变化的信号，并更新`BScanCanvas`实例的`auto_reset_zoom`属性

## 实施步骤
1. 首先在`BScanCanvas`类中添加自动缩放恢复控制标志
2. 然后修改`update_bscan`方法，根据标志决定是否重置坐标轴限制
3. 接着在`create_combined_display`方法中添加GUI开关控件
4. 最后实现开关状态处理方法，连接开关信号到画布属性
5. 测试所有功能，确保修复后的程序符合需求

## 预期效果
- 添加一个"自动恢复缩放"的开关控件
- 当开关开启时，单击点击会自动恢复原始缩放状态（现有行为）
- 当开关关闭时，单击点击不会改变当前的缩放状态
- 用户可以通过开关自由控制是否自动恢复缩放
- 其他功能保持不变，正常工作
