# 超声波探伤项目精度差的原因分析和改进方案

## 关键区别分析

### 1. **编码器结构差异（最关键）**

**EMG手势识别项目**：
```python
self.channels = embeddings.Random(channels, out_features)  # 为每个通道创建随机嵌入
self.signals = embeddings.Level(NUM_LEVELS, out_features, high=20)
samples = torchhd.bind(signal, self.channels.weight.unsqueeze(0))  # 绑定信号和通道
```

**超声波探伤项目**：
```python
self.signals = embeddings.Level(NUM_LEVELS, out_features, high=255)  # 只有信号嵌入
signal = self.signals(input)
samples = torchhd.multiset(signal)  # 没有bind操作
```

**问题**：缺少通道嵌入和bind操作，丢失了重要信息！

### 2. **窗口大小差异**
- EMG：WINDOW = 256（大窗口，捕获更多时序信息）
- 超声波：WINDOW = 31（小窗口，特征不足）

### 3. **信号范围差异**
- EMG：high=20（适合EMG信号范围）
- 超声波：high=255（可能不适合实际深度值187-194）

### 4. **训练评估差异**
- EMG：使用torchmetrics.Accuracy计算训练和测试准确率
- 超声波：没有计算训练准确率，无法监控训练过程

### 5. **数据分割差异**
- EMG：同一数据集随机分割（70%训练，30%测试），确保分布一致
- 超声波：训练集和测试集来自不同目录，可能分布不一致

## 改进方案

### 1. **改进编码器（最重要）**
- 添加通道嵌入（虽然只有1个通道，但可以保持一致性）
- 使用bind操作绑定信号和通道信息
- 调整信号范围参数

### 2. **增大窗口大小**
- 从31改为128或256
- 捕获更多时序信息

### 3. **添加训练准确率计算**
- 在训练后计算训练集准确率
- 监控训练过程，确保训练正确率接近100%

### 4. **添加下采样**
- 类似EMG项目，减少计算量
- 提高泛化能力

### 5. **优化数据分割**
- 使用同一数据集的随机分割
- 确保训练和测试集分布一致

### 6. **调整信号范围**
- 根据实际数据范围调整high参数
- 确保信号嵌入有效

## 预期效果

通过以上改进，应该能够：
- 提高训练准确率（接近100%）
- 提高测试准确率
- 减少过拟合
- 提高模型泛化能力
