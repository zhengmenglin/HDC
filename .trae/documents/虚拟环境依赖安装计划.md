# 虚拟环境依赖安装计划

## 1. 需求分析
根据对项目代码的分析，确定以下依赖库：
- PyQt5 - GUI开发
- PyTorch - 深度学习框架
- torchhd - 超维计算库
- pandas - 数据处理和CSV读写
- numpy - 数值计算
- scikit-learn - DBSCAN聚类算法
- tqdm - 进度条显示
- torchmetrics - 模型评估指标

## 2. 安装步骤

### 步骤1：创建requirements.txt文件
创建一个包含所有依赖的requirements.txt文件，便于统一安装。

### 步骤2：安装依赖
使用pip在虚拟环境中安装所有依赖。

## 3. 预期结果
- 成功安装所有依赖库
- 项目能够正常运行
- GUI能够正常启动
- HDC模型训练和预测功能正常

## 4. 具体操作

1. 创建requirements.txt文件，包含以下内容：
   ```
   PyQt5
   torch
   torchmetrics
   torchhd
   pandas
   numpy
   scikit-learn
   tqdm
   ```

2. 激活虚拟环境并安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

3. 验证安装：
   - 运行main.py，验证GUI是否能正常启动
   - 运行ultrasonic_hdc_emg_style.py，验证模型训练和预测功能是否正常
