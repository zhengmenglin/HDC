# 探伤JSON解析与可视化方案

## 1. JSON结构支持
根据`json格式.md`规范，支持以下事件类型：
- **E**: 间隔编码（横轴坐标）
- **B1/B2**: 第一/第二B显点 [通道号, 深度, 幅度]
- **系统参数**: Sensitivity, GateStart/End, GateLevel, RailBaseStart/End, SignalLossLevel, BoltHoleStart/End, TestRange, ZeroDelay, BeamAngle, BeamWay, BeamOffset, TVG
- **作业信息**: Bureau, Division, Workshop, Area, Team, Operator, DeviceNum, DeviceType, Date, Time, Location, UpDown, LeftRight等
- **其他**: Comment(现场标记), Back(倒车), Remark(标注)

## 2. 实现功能
1. **JSON解析类**: 完整解析所有事件类型
2. **B-Scan可视化**: 以E为横轴绘制B1、B2深度曲线
3. **信息面板**: 在图表右侧显示钢轨参数、通道配置、灵敏度表等

## 3. 输出文件
`parse_flaw_detection_json.py` - 完整解析和可视化脚本

## 4. 使用方式
```bash
python parse_flaw_detection_json.py 123.json
```

## 5. 可视化布局
```
┌──────────────────────────────────────┬────────────────┐
│                                      │  钢轨信息      │
│     B1/B2点深度曲线                  │  通道配置      │
│     (X轴=编码间隔E, Y轴=深度mm)      │  灵敏度表      │
│                                      │  闸门参数      │
│                                      │  作业信息      │
└──────────────────────────────────────┴────────────────┘
```
