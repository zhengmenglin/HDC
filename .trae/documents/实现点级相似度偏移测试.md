# 点级相似度偏移测试实现计划

## 目标
设计并实现一个测试函数，用于评估不同通道偏移量对同一个点的相似度变化的影响，使用指定的标注文件中的点。

## 实现步骤

### 1. 设计新的测试函数 `run_point_similarity_offset_test`
- 基于现有的 `run_channel_offset_test` 函数结构
- 专注于追踪特定点的相似度变化，而不是整体分类指标
- 从指定的标注文件 `170921_16229片段.xxc标注.json` 中选择测试点

### 2. 选择测试点
从标注文件中选择以下代表性点：
- 通道6: e=592, depth=90.0（螺孔中心点）
- 通道7: e=853, depth=79.0（螺孔中心点）
- 通道8: e=875, depth=64.0（螺孔中心点）

### 3. 修改 `test_channel_offset` 函数
- 添加参数 `target_encoding` 用于指定要追踪的点
- 修改返回值，不仅返回分类指标，还返回目标点的相似度值
- 确保能够准确提取目标点的相似度数据

### 4. 实现相似度数据提取逻辑
- 在预测后，根据 `target_encoding` 找到对应的样本
- 提取该样本在每个通道的正常类和伤损类相似度
- 处理可能的边界情况（如目标点不存在）

### 5. 生成相似度变化图表
- 为每个通道创建单独的图表
- 展示正常类相似度和伤损类相似度随偏移量的变化
- 使用不同颜色的曲线区分正常类和伤损类
- 添加适当的标题、标签和图例

### 6. 保存测试结果
- 将相似度数据保存为 JSON 文件，便于后续分析
- 确保结果目录结构清晰，便于管理

## 技术要点

- **复用现有代码**：尽可能复用现有的数据处理、模型加载和预测逻辑
- **精确点定位**：确保能够准确找到并提取目标点的相似度数据
- **可视化**：使用 matplotlib 生成清晰的相似度变化图表
- **鲁棒性**：处理可能的边界情况，如目标点不存在或数据格式错误

## 预期输出

- 每个通道的相似度变化图表，展示正常类和伤损类相似度随偏移量的变化
- 详细的相似度数据 JSON 文件，便于后续分析
- 控制台输出测试进度和结果摘要
