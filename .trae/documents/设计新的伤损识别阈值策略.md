# 问题分析

当前系统的伤损识别逻辑存在以下问题：
1. **正常类样本过多**：导致正常类（索引0）的相似度始终很高（0.9左右）
2. **伤损类难以超过正常类**：伤损类相似度（0.8左右）始终低于正常类
3. **判定逻辑不合理**：当前逻辑要求伤损类相似度必须高于正常类+margin，这在当前数据分布下几乎不可能实现

# 解决方案

## 新的阈值策略：基于类别自身阈值

### 1. 修改配置文件
- **predict_threshold**：设置为每个伤损类别的最低相似度要求（例如0.75）
- **predict_margin**：设置为0，不再使用与正常类的比较

### 2. 修改预测逻辑
- **移除与正常类的比较**：不再要求伤损类相似度高于正常类
- **基于自身阈值判断**：只要伤损类相似度超过其自身阈值，就判定为伤损
- **保持多通道融合**：继续使用9通道并行预测提高准确性

### 3. 具体实现
修改 `hdc_point_level_classifier.py` 中的 `predict` 方法：
```python
# 原逻辑
is_defect = (max_defect_sim > threshold) & (max_defect_sim > (normal_sim + margin))

# 新逻辑
is_defect = (max_defect_sim > threshold)
```

### 4. 调优建议
- **阈值选择**：根据不同伤损类别的相似度分布设置合适的阈值
- **通道权重**：考虑为不同通道设置不同的权重，提高关键通道的影响力
- **后处理**：增加连续窗口一致性检查，减少孤立误报

# 预期效果

- **提高伤损识别率**：不再受正常类高相似度的限制
- **保持低误报率**：通过合理设置阈值过滤噪声
- **适应数据分布**：更灵活地处理正常样本过多的情况
