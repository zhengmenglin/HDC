# NeuralHD 分类器替换计划

## 1. 导入修改
- 将 `from torchhd.classifiers import OnlineHD` 替换为 `from torchhd.classifiers import NeuralHD`

## 2. 模型类修改
- 修改 `HDCPointLevelModelChannel8` 类，使用 NeuralHD 分类器替代自定义 Centroid 模型
- 移除自定义编码器实现，使用 NeuralHD 的 Sinusoid 编码器

## 3. 训练方法修改
- 修改 `train` 方法，适配 NeuralHD 的训练逻辑
- 移除自定义的 OnlineHD 训练实现，使用 NeuralHD 的 `fit` 方法
- 添加 NeuralHD 特有的参数支持（如 regen_freq、regen_rate）

## 4. 预测方法修改
- 确保预测逻辑与 NeuralHD 兼容
- 保持类别 0、11、13 相似度记录功能

## 5. 配置参数修改
- 在配置文件中添加 NeuralHD 相关参数
- 确保训练过程中使用正确的参数

## 6. 测试与验证
- 运行修改后的代码，确保功能正常
- 验证预测结果和相似度记录是否正确

- 保持原有功能不变（只使用通道8、记录类别相似度）
- 利用 NeuralHD 的维度再生机制提高分类准确率
