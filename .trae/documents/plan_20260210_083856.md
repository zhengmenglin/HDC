# mixed 策略平衡实现计划

## 修改内容

### 1. 修改 _load_data 方法的逻辑结构

**引入临时样本存储**：
- 为每个文件创建临时列表 `normal_samples` 和 `flaw_samples`
- 在滑动窗口采样过程中，根据中心点标签将样本分类存储

### 2. 实现 mixed 策略的平衡逻辑

**平衡样本数量**：
- 对于 mixed 策略，计算伤损样本的数量
- 随机选取相同数量的正常样本
- 合并伤损样本和选取的正常样本，创建平衡数据集

### 3. 保持其他策略逻辑不变

**确保兼容性**：
- damage_only 策略：只保留中心点是伤损的样本
- all 策略：使用所有数据，不做任何过滤

## 技术实现要点

1. **样本分类**：在滑动窗口采样过程中，根据中心点标签将样本分为正常和伤损两类
2. **随机采样**：使用 numpy 的随机采样功能，确保正常样本的选取是随机的
3. **平衡控制**：确保混合策略下正常样本和伤损样本数量相等
4. **数据完整性**：保留所有原始数据，确保滑动窗口能够覆盖所有可能的中心点

## 预期效果

- mixed 策略：创建平衡的训练数据集，正常样本和伤损样本数量相等
- damage_only 策略：只使用伤损样本
- all 策略：使用所有数据

## 实现步骤

1. 修改 _load_data 方法，引入临时样本存储
2. 实现样本分类逻辑
3. 实现 mixed 策略的平衡逻辑
4. 测试修改后的代码，确保所有策略正常工作
