# 修复钢轨探伤B显数据可视化工具的问题

## 问题分析
1. **没有高亮显示已选中的点**：当前程序可能没有正确实现点的高亮显示功能。
2. **已选中的点信息只显示当前选中的，不是所有已选择的，且默认不是多选模式**：点选择逻辑和显示逻辑需要调整。
3. **已标注的列表选项框显示不全，布局不合理**：UI布局需要优化，合理利用空白空间。
4. **标注框样式需要改进**：线框和文字位置需要调整。
5. **只能标注伤损，不能标注正常结构**：类型选择需要添加正常结构选项。

## 修复计划

### 1. 修复已选中点的高亮显示
   - 检查 `highlight_selected_points` 方法，确保它正确绘制选中点的高亮效果
   - 确保在更新B显图像时，选中点的高亮效果不会被覆盖

### 2. 修复点选择和显示逻辑
   - 修改 `select_single_point` 方法，默认启用多选模式
   - 确保选中的所有点都显示在信息区域
   - 调整键盘事件处理，确保Shift和Ctrl键能正确切换多选模式

### 3. 优化UI布局
   - 调整已标注列表选项框的宽度，确保显示完整
   - 将已标注的结构和伤损与选中的点并排显示，合理利用空白空间
   - 调整各组件的布局比例，提高界面利用率

### 4. 改进标注框样式
   - 修改标注框绘制逻辑，确保线框清晰可见
   - 将文字描述移动到框的旁边，而不是上方
   - 优化文字大小和样式，提高可读性

### 5. 添加正常结构标注功能
   - 在类型选择中添加正常结构选项
   - 更新子类型列表，根据选择的类型（伤损或结构）动态更新
   - 确保标注管理器能正确处理结构类型的标注

## 实施步骤
1. 首先修复点选择和高亮显示问题
2. 然后优化UI布局
3. 接着改进标注框样式
4. 最后添加正常结构标注功能
5. 测试所有功能，确保修复后的程序符合需求

## 预期效果
- 选中的点能正确高亮显示
- 支持默认多选模式，所有选中的点都能在信息区域显示
- UI布局合理，各组件显示完整，空间利用充分
- 标注框样式清晰，文字描述位置合理
- 既能标注伤损，也能标注正常结构
