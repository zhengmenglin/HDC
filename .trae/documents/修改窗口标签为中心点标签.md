## 修改窗口标签逻辑

将 `test_channel8_only.py` 第130-134行的窗口标签确定逻辑从"窗口内统计"改为"中心点标签"：

**修改前：**
```python
# 新逻辑：窗口内所有点都是伤损点，才标记为伤损
if np.any(window_labels != 0):
    label = max(set(window_labels), key=list(window_labels).count)
else:
    label = 0
```

**修改后：**
```python
# 窗口标签=中心点标签
center = (start + end) // 2
label = labels[center]
```

这样训练和预测的逻辑就保持一致了（都是基于窗口中心点）。
