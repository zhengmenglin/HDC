# Fix for HDC Model Testing Error

## Problem Analysis

The error is occurring because of a shape mismatch between training and test data formats:

```
RuntimeError: The size of tensor a (8) must match the size of tensor b (9) at non-singleton dimension 1
```

### Root Cause

1. **Old format (training data)**: Samples have shape [64, 27] after processing, then transformed to [8, 27]
2. **New format (test data)**: Samples are flattened [1728] features, but transform is directly applied without reshaping
3. **Result**: Test samples become [8] instead of [8, 27], causing dimension mismatch in the encoder

## Solution

### Fix the new format processing in `ultrasonic_hdc_emg_style.py`:

1. **Reshape new format samples** from [1728] to [64, 27] before applying transform
2. **Apply transform** to get [8, 27], matching old format shape
3. **Ensure consistent shape** for both formats throughout processing

### Implementation Steps

1. Modify the new format processing in the `_load_data` method
   - Reshape flattened features [1728] to [64, 27] 
   - Apply transform to get [8, 27]
   - Add to samples list

2. Verify shape consistency between old and new formats

## Expected Result

- Both old and new format samples will have the same shape [8, 27] after processing
- The encoder will receive consistent input shape [batch, 8, 27]
- No dimension mismatch during binding operation
- Successful model evaluation with accurate predictions
