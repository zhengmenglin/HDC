## 实施计划

### 修改位置
在 `Channel8Dataset` 类的 `_load_all_data` 方法中（第129-144行的窗口生成循环）

### 修改内容
在生成窗口样本后、确定窗口标签后，添加以下逻辑：

1. **检查窗口标签是否为缺陷**（label != 0）
2. **如果是缺陷窗口**，则：
   - 获取窗口内所有点的标签：`window_labels = labels[start:end]`
   - 将非缺陷点（window_labels == 0）对应的通道值改为0
   - 保持缺陷点（window_labels != 0）的通道值不变

### 具体实现
在确定窗口标签后（第140行之后），添加条件判断和数据修改逻辑：
```python
# 如果窗口标签为缺陷，将窗口内非缺陷点的通道值改为0
if label != 0:
    window_labels = labels[start:end]
    non_defect_mask = (window_labels == 0)
    sample[non_defect_mask] = 0
```

这样可以确保缺陷窗口中只有缺陷点保留原始通道值，非缺陷点的通道值被清零。
