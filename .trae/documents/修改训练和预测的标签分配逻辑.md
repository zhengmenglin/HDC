## 修改训练和预测的标签分配逻辑

### 问题分析

**当前训练逻辑**（第115-142行）：
```python
window_labels = labels[start:end]
if len(window_labels) > 0:
    label = max(set(window_labels), key=list(window_labels).count()
else:
    label = 0
```
- **逻辑**：窗口内只要有一个伤损点，就标记为伤损
- **问题**：如果窗口内只有一个中心点是伤损，其他点都是正常，模型学习的是"中心点=伤损"，而不是"窗口内所有点=伤损"

**当前预测逻辑**（第326-327行）：
```python
center = (start + end) // 2  # 计算窗口中心
df.loc[center, 'predicted_label_8'] = pred_label  # 只标记中心点
```
- **逻辑**：只标记窗口中心点为伤损
- **问题**：训练和预测的标签分配逻辑不一致

### 修改方案

#### 方案1：修改训练逻辑（推荐）
修改训练时的标签分配逻辑：
```python
# 确定窗口标签
window_labels = labels[start:end]

# 新逻辑：窗口内所有点都是伤损点，才标记为伤损
if np.any(window_labels != 0):  # 窗口内有伤损点
    label = max(set(window_labels), key=list(window_labels).count()
else:
    label = 0
```

#### 方案2：修改预测逻辑
修改预测时的标签分配逻辑：
```python
# 新逻辑：窗口内所有点都是伤损点，才标记为伤损
if np.any(window_labels != 0):  # 窗口内有伤损点
    label = max(set(window_labels), key=list(window_labels).count()
else:
    label = 0
```

### 预期效果

- **训练时**：窗口内所有点都是伤损点，才标记为伤损
- **预测时**：窗口内所有点都是伤损点，才标记为伤损
- **一致性**：训练和预测的标签分配逻辑一致
- **性能**：可能略有下降（因为更严格的标签），但更合理

### 推荐方案

- 优点：训练和预测逻辑一致
- 缺点：需要重新训练模型

**推荐方案2**：修改预测逻辑（中优先级）
