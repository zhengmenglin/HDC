# 钢轨探伤B显数据JSON解析与可视化工具实现计划

## 1. 项目概述
本计划旨在实现一个窗口上位机版本的钢轨探伤B显数据JSON解析与可视化工具，增加X轴可拖动条和数据标注功能。

## 2. 技术栈选择
- **GUI框架**：PyQt5（功能强大，界面美观）
- **可视化库**：matplotlib（已在原代码中使用）
- **数据处理**：Python 3.x + JSON库
- **数学计算**：math库（已在原代码中使用）

## 3. 实现步骤

### 3.1 准备工作
- 安装必要的库：`pip install PyQt5 matplotlib`
- 创建项目目录结构
- 备份原代码

### 3.2 窗口上位机实现
1. **创建主窗口类**：
   - 继承`QMainWindow`类
   - 设计UI布局，包含菜单栏、工具栏、主显示区域和状态栏
   - 添加X轴滑动条控件

2. **集成现有功能**：
   - 将原有的`FlawDetectionDataParser`类集成到主窗口中
   - 将原有的`visualize_bscan`函数改造为类方法，集成到主窗口中
   - 实现JSON文件加载和解析功能

3. **X轴滑动条实现**：
   - 在主窗口底部添加`QSlider`控件
   - 设置滑动条范围为最小编码值到最大编码值
   - 实现滑动条值变化时的回调函数，更新显示的B显图像
   - 实现滑动条与鼠标滚轮缩放的联动

### 3.3 数据标注功能实现
1. **类型选择界面**：
   - 创建类型选择对话框
   - 分为伤损类型和结构类型两个标签页
   - 伤损类型：轨头外侧核伤、轨头中心核伤、轨头内侧核伤等
   - 结构类型：接头、螺孔、导线孔、焊缝等

2. **点选择功能**：
   - 实现鼠标事件处理：点击、拖拽、滚轮
   - 支持框选多个点（通过拖拽实现）
   - 支持单击选择单个点
   - 支持按住Shift键多选
   - 支持取消选择
   - 高亮显示选中的点

3. **标注数据生成**：
   - 将选中的点按照编码值排序
   - 生成JSON格式的标注数据
   - 标注数据包含：id、类型、子类型、点数据、编码值范围、通道信息、时间戳等

4. **标注数据保存和加载**：
   - 实现标注数据保存功能，保存为JSON文件
   - 实现标注数据加载功能，加载已有标注
   - 实现标注数据编辑和删除功能

### 3.4 测试和调试
1. 测试JSON文件加载和解析功能
2. 测试B显数据可视化功能
3. 测试X轴滑动条功能
4. 测试点选择功能
5. 测试类型选择界面
6. 测试标注数据生成和保存功能
7. 调试和修复问题

## 4. 代码结构

### 4.1 核心类
- **MainWindow**：主窗口类，负责UI布局和事件处理
- **FlawDetectionDataParser**：数据解析类，负责JSON文件加载和解析
- **AnnotationManager**：标注管理类，负责标注数据的生成、保存和加载
- **PointSelector**：点选择类，负责处理点的选择和取消选择

### 4.2 核心文件
- **parse_flaw_detection_json.py**：原代码，包含数据解析和可视化功能
- **main_window.py**：主窗口实现
- **annotation_manager.py**：标注管理实现
- **point_selector.py**：点选择实现
- **type_selector.py**：类型选择界面实现
- **main.py**：程序入口

### 5.2 X轴滑动条功能
- 滑动条范围：最小编码值到最大编码值
- 滑动条步长：1
- 滑动条页步长：10
- 拖动滑动条时，实时更新显示的B显图像
- 滑动条与鼠标滚轮缩放联动：缩放时，滑动条范围自动调整

### 5.3 数据标注流程
1. 加载JSON文件
2. 可视化B显数据
3. 点击"标注"按钮，打开类型选择对话框
4. 选择标注类型（伤损类型或结构类型）
5. 在B显图像上选择要标注的点
6. 点击"保存标注"按钮，生成并保存标注数据
