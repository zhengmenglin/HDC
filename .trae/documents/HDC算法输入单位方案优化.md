# HDC算法输入单位优化方案

## 核心问题分析

根据需求文档和超维计算原理，伤损由多个点构成，需要保留空间关联性，同时要处理不同大小的伤损。

### 需求要点：
1. 一个伤损由多个点构成，相近的编码值表示空间关联
2. 循环移位编码用于表示多个点的深度值
3. 伤损可能由多个通道的点构成
4. 伤损大小不一，包含不同数量的点

## 优化方案设计

### 1. 采用可变长度伤损区域作为输入单位

**核心思路**：
- 以完整的伤损区域作为基本训练单位
- 使用循环移位编码将多个点编码为一个超维向量
- 支持不同大小的伤损区域

### 2. 实现滑动窗口伤损检测

**训练阶段**：
1. 从标注文件中提取完整的伤损区域
2. 对每个伤损区域，提取所有构成该伤损的点
3. 使用循环移位编码将这些点编码为一个超维向量
4. 训练HDC分类器

**识别阶段**：
1. 使用滑动窗口扫描整个B显数据
2. 对每个窗口内的点，使用循环移位编码生成超维向量
3. 使用训练好的模型进行预测
4. 合并相邻的伤损预测结果

### 3. 完善循环移位编码实现

**修改内容**：
- 改进 `circular_shift_encode` 方法，支持可变长度的点序列
- 添加 `encode_damage_region` 方法，用于编码完整的伤损区域
- 实现基于区域的训练和预测功能

### 4. 实现标注数据加载功能

**新增功能**：
- 从标注JSON文件中提取伤损区域
- 支持多种伤损类型和正常结构类型
- 将标注数据转换为训练样本

## 代码修改计划

### 1. 改进HDC.py文件

**修改点**：
- 在 `HyperdimensionalEncoder` 类中完善循环移位编码
- 新增 `encode_damage_region` 方法
- 在 `BScanDataProcessor` 类中添加标注数据加载功能
- 改进 `HDCClassifier` 类，支持基于区域的训练和预测

### 2. 实现训练脚本

**创建文件**：`hdc_train.py`
**功能**：
- 加载训练数据和标注
- 训练HDC模型
- 保存训练好的模型

### 3. 实现测试脚本

**创建文件**：`hdc_test.py`
**功能**：
- 加载测试数据
- 使用训练好的模型进行预测
- 生成测试数据的标注JSON

## 预期效果

1. **保留空间关联性**：通过循环移位编码保留伤损内部点的空间关系
2. **支持不同大小伤损**：使用可变长度编码处理不同数量的点
3. **提高识别准确率**：基于完整伤损区域训练，更符合实际应用场景
4. **灵活的输入方式**：支持单个点和伤损区域两种输入模式

## 实施步骤

1. 改进循环移位编码实现
2. 添加标注数据加载功能
3. 实现基于区域的训练和预测
4. 编写训练和测试脚本
5. 测试整个流程

这个方案既符合超维计算原理，又满足了实际应用需求，能够有效处理不同大小的伤损识别问题。
