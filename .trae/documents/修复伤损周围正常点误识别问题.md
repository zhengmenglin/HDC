# 修复伤损周围正常点误识别问题

## 问题根源
1. **滑动窗口重叠严重**：WINDOW=32, STEP=1，窗口间有31个点重叠
2. **标签分配策略**：整个窗口标签由中心点决定，导致训练数据污染
3. **信号特征相似**：深度值187-194非常接近，难以区分
4. **训练数据重复**：一个伤损点产生32个相似的"伤损窗口"

## 修复方案

### 1. 增大滑动窗口步长（立即修复）
- 将 `DEFAULT_STEP` 从 1 改为 8 或 16
- 减少窗口重叠，降低重复样本

### 2. 改进标签分配策略（中期优化）
- 不再使用中心点标签
- 使用多数投票或阈值判断确定窗口标签
- 减少训练数据污染

### 3. 添加差分特征（长期改进）
- 在编码器中计算信号差分
- 增强信号变化检测能力
- 提高模型对伤损边界的识别

### 4. 添加预测结果过滤（后处理）
- 过滤掉孤立的预测点
- 只保留连续的伤损区域
- 进一步减少误报

## 实施顺序
1. 先修改步长参数（最简单，效果最明显）
2. 改进标签分配策略
3. 添加差分特征
4. 添加后处理过滤

## 预期效果
- 显著减少伤损周围正常点的误识别
- 提高精确率
- 减少训练时间和计算资源消耗
