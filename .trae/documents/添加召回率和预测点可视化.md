## 修改通道8实验脚本，添加召回率和预测点可视化

### 1. 修改准确率计算函数 (calculate_channel8_accuracy)
**同时计算精确率、召回率和F1分数**：
- 精确率 = 预测正确的点数 / 所有预测出的点数（当前已有）
- 召回率 = 预测正确的点数 / 所有真实伤损点数
- F1分数 = 2 * 精确率 * 召回率 / (精确率 + 召回率)

### 2. 修改HDC JSON生成逻辑
在 `csv_to_hdc_json.py` 中添加预测点标识：
- 在生成的 annotation 对象中添加 `"source": "predicted"` 字段
- 这样上位机可以根据 `source` 字段区分：
  - 手动标注的点（无 source 字段或 source 为 "manual"）
  - 自动预测的点（source 为 "predicted"）
- 上位机可以使用不同颜色显示预测点

### 3. 修改主测试流程
- 在准确率计算部分输出精确率、召回率和F1分数
- 调用 CSV 到 HDC JSON 转换时，确保预测点带有标识字段

### 4. 输出格式
```
文件名: 准确率 = 0.2636, 召回率 = 1.0000, F1分数 = 0.4171
```
