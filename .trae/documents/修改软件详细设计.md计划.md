# 修改软件详细设计.md计划

## 1. 更新系统架构
- **替换过时模块**：将 `ultrasonic_hdc_emg_style.py` 替换为 `hdc_point_level_classifier.py`
- **更新识别模块**：移除 `csv_to_hdc_json.py`，改为在 `test_hdc_point_level_full.py` 中集成结果转换功能
- **调整测试管道**：移除 `test_channel8_only.py` 和 `test_full_pipeline.py`，改为 `test_hdc_point_level_full.py`
- **明确主入口**：添加 `main.py` 作为GUI应用主入口

## 2. 修改数据流程设计
- **更新文件转换关系**：
  - 原始JSON → hdc.csv（使用UltrasonicDataConverter）
  - hdc.csv → 训练 → 模型文件（.pth）
  - hdc.csv → 预测 → predicted_label.csv → predicted.json
- **简化BeamOffset处理**：统一为 `adjusted_e = original_e + beam_offset[channel]`

## 3. 更新核心算法设计
- **替换HDC模型**：从Centroid-based模型改为HDCPointLevelModel
- **简化编码流程**：移除n-gram等复杂编码，使用更直接的超维编码
- **更新预测机制**：添加Margin逻辑过滤误报，支持单通道和多通道模式
- **调整聚类算法**：简化为基于预测标签的直接分组，不再使用DBSCAN

## 4. 调整数据格式设计
- **更新中间文件命名**：
  - 训练CSV：`{原始文件名}_hdc.csv`
  - 标签CSV：`{原始文件名}_label.csv`
  - 预测结果CSV：`{原始文件名}_predicted_label.csv`
  - 可视化JSON：`{原始文件名}_predicted.json`
- **简化标注格式**：统一手动标注和HDC预测的JSON格式，使用`source`字段区分

## 5. 更新模块详细设计
- **数据转换模块**：基于 `ultrasonic_data_converter.py` 重写
- **HDC训练与识别**：基于 `hdc_point_level_classifier.py` 重写
- **GUI模块**：保持现有设计，补充PyQt5实现细节
- **测试流程**：基于 `test_hdc_point_level_full.py` 重写完整测试流程

## 6. 修改技术指标
- **调整窗口大小**：从36改为128（可配置）
- **更新通道映射**：保持0-8直接映射
- **移除聚类算法**：不再使用DBSCAN
- **更新可视化支持格式**：保持不变

## 7. 补充GUI实现细节
