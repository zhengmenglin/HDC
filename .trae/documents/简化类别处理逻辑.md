## 修改通道8实验脚本，简化类别处理

### 修改内容
在 `train_channel8_model` 函数中：

**当前代码（L208-212）**：
```python
# 获取所有唯一标签
all_labels = train_ds.labels
max_label = max(all_labels)
num_classes = int(max_label + 1)
print(f"检测到 {num_classes} 个唯一类别（标签 0 到 {max_label}）")
```

**修改为**：
```python
# 固定使用20个类别（0-19：正常+19种伤损类型）
num_classes = 20
print(f"使用固定类别数: {num_classes}（标签 0 到 19）")
```

### 理由
1. 伤损类型是固定的，不需要动态计算
2. 只使用通道8的数据，忽略其他通道
3. 代码更简洁，逻辑更清晰
