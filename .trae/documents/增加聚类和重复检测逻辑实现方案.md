# 增加聚类和重复检测逻辑实现方案

## 问题分析
当前系统使用滑动窗口（大小12，步长1）对数据进行扫描，每个窗口生成独立的预测结果。这导致同一个目标会被多个相邻窗口检测到，在最终的hdc.json文件中产生大量重复的标注。

## 解决方案设计

### 1. 重新启用并优化聚类功能
- 修改`csv_to_hdc_json.py`中的`skip_clustering`参数，默认不跳过聚类
- 增强`cluster_points`方法，支持多通道标签聚类
- 调整DBSCAN参数，优化聚类效果

### 2. 实现多通道标签聚类算法
- 对每个通道的预测结果分别进行聚类
- 考虑通道间的空间关系，合并相关通道的聚类结果
- 使用共享的坐标转换逻辑确保聚类准确性

### 3. 增加重复检测和合并逻辑
- 实现相邻窗口预测结果的合并算法
- 基于时间连续性和空间重叠度合并重复检测结果
- 设计基于E值范围和通道信息的合并策略

### 4. 后处理优化
- 合并相邻或重叠的伤损结构
- 基于伤损类型和位置信息去重
- 保留最准确的预测结果

## 实现步骤

### 1. 修改csv_to_hdc_json.py
- 将`skip_clustering`默认值改为`False`
- 优化`cluster_points`方法，支持多通道标签
- 调整DBSCAN参数：`eps=15.0`，`min_samples=2`

### 2. 增强cluster_points方法
- 支持从预测结果中提取多通道标签
- 为每个通道生成独立的聚类特征
- 使用坐标转换后的特征进行聚类
- 合并相关通道的聚类结果

### 3. 实现合并相邻预测结果的后处理
- 按通道和E值范围排序标注
- 遍历标注，合并相邻或重叠的区域
- 计算合并后的区域的统一标签
- 更新标注的start_E和end_E

### 4. 优化generate_hdc_json方法
- 支持处理合并后的聚类结果
- 生成更准确的伤损结构信息
- 确保标注的完整性和准确性

## 预期效果
- 减少hdc.json文件中的重复标注
- 提高标注的准确性和可读性
- 同一目标只生成一个伤损结构
- 保留详细的通道和位置信息

## 关键代码修改点
1. `csv_to_hdc_json.py` - `convert_csv_to_hdc_json`方法：启用聚类
2. `csv_to_hdc_json.py` - `cluster_points`方法：支持多通道标签聚类
3. `csv_to_hdc_json.py` - 新增合并相邻标注的后处理方法
4. `csv_to_hdc_json.py` - `generate_hdc_json`方法：处理合并后的结果

该方案将有效解决多个窗口检测同一目标多次的问题，提高标注质量和系统性能。
