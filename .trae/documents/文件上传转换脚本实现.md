# 文件上传转换脚本实现

## 功能需求
1. 查找脚本所在路径及其子目录下的所有 `.xxc`、`.gcb`、`.cap` 文件
2. 将找到的文件依次上传至 `http://member.xtxf.com/index/user/convert.html` 进行转换
3. 将转换后的 JSON 数据下载至原文件同级目录，命名为 `原文件名.json`

## 实现方案

### 1. 脚本结构设计
- 使用 Python 编写，依赖 `requests` 库
- 采用面向对象设计，封装文件查找、上传、下载功能
- 包含错误处理和日志记录

### 2. 核心功能模块

#### 2.1 文件查找模块
- 使用 `pathlib` 模块遍历目录树
- 筛选指定扩展名的文件
- 记录文件路径和文件名

#### 2.2 文件上传模块
- 使用 `requests.post` 发送多部分表单请求
- 处理上传进度和响应
- 支持错误重试机制

#### 2.3 结果下载模块
- 解析服务器响应，获取转换后的 JSON 数据
- 将数据保存至指定路径
- 验证文件保存完整性

### 3. 脚本执行流程
1. 获取脚本所在目录路径
2. 遍历查找所有目标文件
3. 遍历文件列表，依次执行：
   - 上传文件至转换服务器
   - 接收转换后的 JSON 数据
   - 保存数据至原文件同级目录
4. 输出执行结果统计

### 4. 错误处理
- 网络连接错误处理
- 文件读写错误处理
- 服务器响应错误处理
- 重试机制（3次重试）

### 5. 日志记录
- 记录脚本执行过程
- 记录成功和失败的文件
- 记录详细错误信息

## 代码实现

脚本将保存为 `file_converter.py`，包含以下核心代码：

```python
import os
import requests
from pathlib import Path
import logging
import time

# 配置日志
logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)

class FileConverter:
    def __init__(self, upload_url, file_extensions):
        self.upload_url = upload_url
        self.file_extensions = file_extensions
        self.scripts_dir = Path(__file__).parent
    
    def find_files(self):
        # 查找脚本所在目录及其子目录下的所有目标文件
        files = []
        for ext in self.file_extensions:
            files.extend(self.scripts_dir.rglob(f"*.{ext}"))
        return files
    
    def upload_file(self, file_path):
        # 上传文件至转换服务器
        retry_count = 3
        for i in range(retry_count):
            try:
                with open(file_path, 'rb') as f:
                    files = {'file': (file_path.name, f)}
                    response = requests.post(self.upload_url, files=files, timeout=30)
                    response.raise_for_status()
                    return response.json()
            except Exception as e:
                logger.error(f"上传文件 {file_path} 失败 (尝试 {i+1}/{retry_count}): {e}")
                if i < retry_count - 1:
                    time.sleep(2)
                else:
                    raise
    
    def save_result(self, file_path, data):
        # 保存转换结果至原文件同级目录
        result_path = file_path.with_suffix('.json')
        with open(result_path, 'w', encoding='utf-8') as f:
            import json
            json.dump(data, f, ensure_ascii=False, indent=2)
        return result_path
    
    def process_files(self):
        # 处理所有找到的文件
        files = self.find_files()
        logger.info(f"找到 {len(files)} 个目标文件")
        
        success_count = 0
        failure_count = 0
        
        for file_path in files:
            try:
                logger.info(f"开始处理文件: {file_path}")
                result_data = self.upload_file(file_path)
                result_path = self.save_result(file_path, result_data)
                logger.info(f"文件处理成功: {result_path}")
                success_count += 1
            except Exception as e:
                logger.error(f"文件处理失败 {file_path}: {e}")
                failure_count += 1
        
        logger.info(f"处理完成: 成功 {success_count} 个, 失败 {failure_count} 个")
        return success_count, failure_count

def main():
    UPLOAD_URL = "http://member.xtxf.com/index/user/convert.html"
    FILE_EXTENSIONS = ["xxc", "gcb", "cap"]
    
    converter = FileConverter(UPLOAD_URL, FILE_EXTENSIONS)
    converter.process_files()

if __name__ == "__main__":
    main()
```

## 使用说明
1. 确保已安装 `requests` 库：`pip install requests`
2. 将脚本保存为 `file_converter.py`
3. 在需要查找文件的目录下执行脚本
4. 脚本将自动查找并处理所有符合条件的文件

## 注意事项
1. 脚本需要网络连接才能正常工作
2. 请确保目标服务器支持文件上传和转换功能
3. 建议先测试少量文件，确认转换效果后再批量处理
4. 脚本将在原文件同级目录生成转换结果，请注意备份原文件
