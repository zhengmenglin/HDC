# 分类器选择分析

## 为什么选择 OnlineHD 而不选择其他分类器

1. **在线学习能力**：OnlineHD 专为在线学习设计，支持单遍和多遍训练，适应数据流场景。

2. **训练效率**：使用 Sinusoid 编码器，结合在线更新方法 `add_online`，训练速度快。

3. **鲁棒性**：根据论文描述，OnlineHD 对噪声和异常值具有较强的鲁棒性。

4. **实现复杂度**：相比其他复杂分类器（如 NeuralHD、DistHD），OnlineHD 实现相对简单，同时保持良好性能。

5. **多轮训练支持**：通过 epochs 参数支持多轮训练，有助于提高模型精度。

6. **学习率控制**：提供学习率参数，允许用户根据具体任务调整。

## 岭回归的局限性

1. **一次性学习**：IntRVFL 中的岭回归实现是一次性学习（batch learning），不支持在线更新。

2. **固定表示**：使用固定的密度编码（Density encoding），缺乏自适应能力。

3. **正则化参数敏感**：性能对 alpha 参数选择较为敏感，需要仔细调优。

4. **计算复杂度**：当数据量较大时，矩阵求逆操作可能变得计算密集。

5. **特征交互**：线性模型本质限制了对复杂特征交互的捕获能力。

## 如何确定岭回归正则化参数

1. **交叉验证**：使用 k-fold 交叉验证，在不同 alpha 值下评估模型性能。

2. **网格搜索**：在合理范围内（如 0.001 到 1000）搜索最佳 alpha 值。

3. **贝叶斯优化**：对于计算资源有限的情况，使用贝叶斯优化高效寻找最优参数。

4. **经验法则**：根据数据规模和特征维度，选择合适的初始 alpha 值。

5. **监控验证误差**：绘制不同 alpha 值对应的验证误差曲线，选择误差最小的点。
