# 实现计划：增加实时修改最后一个选中点信息的功能

## 功能需求
1. 增加一个功能，能够实时修改最后一个选中的点的相关信息
2. 在修改框预填 "1. E:801 Ch:8 深度:62.0 幅度:100.0" 这样的信息
3. 可以修改深度和幅度
4. 点击修改后更新对应的原始数据和标注数据

## 实现步骤

### 1. 创建点信息修改对话框
- 创建一个新的对话框类 `PointEditorDialog`，用于编辑点的深度和幅度信息
- 对话框应包含：
  - 显示点的基本信息（E值、通道）
  - 深度输入框（可编辑）
  - 幅度输入框（可编辑）
  - 确定和取消按钮

### 2. 在主窗口中添加修改点按钮
- 在选中点信息显示区域添加一个 "修改最后选中点" 按钮
- 按钮应在有选中点时启用，无选中点时禁用

### 3. 实现修改点信息的逻辑
- 在 `MainWindow` 类中添加 `edit_last_selected_point` 方法
- 该方法应：
  - 获取最后一个选中的点
  - 打开修改对话框，预填点的信息
  - 接收用户修改后的深度和幅度值
  - 更新原始数据中的对应点信息
  - 更新标注数据中的对应点信息
  - 刷新界面显示

### 4. 实现数据更新逻辑
- 实现 `update_point_in_json` 方法，用于更新原始JSON文件中的点信息
- 实现 `update_point_in_annotations` 方法，用于更新标注数据中的点信息
- 确保修改后的数据能够正确保存和显示

### 5. 测试和优化
- 测试修改功能是否正常工作
- 确保界面响应及时
- 优化用户体验

## 技术要点
- 使用 PyQt5 的对话框组件创建修改界面
- 复用现有的 JSON 数据处理逻辑
- 确保修改操作的原子性，避免数据不一致
- 保持代码风格与现有代码一致
