探伤实训装置JSON结构说明
1 概述
为了方便技术交流沟通，并将不同型号和版本的超声波探伤仪生成的B显数据转换成统一的数据结构，遵循以下原则设计此数据交换格式：
1.	不对现场仪器进行升级改造，只对现有已经在铁路应用的数据进行转换；
2.	可读性强，采用标准专业词语命名和十进制数值表达各种参数；
3.	具有扩展性，为未来可能出现的新信息预留位置；
4.	尽量减小输出数据量的大小。
2 数据交换格式
数据交换的代码格式采用JSON格式。JSON的全称为JavaScript Object Notation，是基于ECMAScript（欧洲计算机协会制定的js规范）的一个子集，采用完全独立于语言的文本格式，但是也使用了类似于C语言家族的习惯（包括C, C++, C#,Java,JavaScript,Perl,Python等），在各种开发工具软件中都有类库可以调用。这些特性使JSON易于人阅读和编写，同时也易于机器解析和生成，成为理想的数据交换语言。
本系统JSON结构为一个list型数组，数组中每一个JSON对象代表每一个编码脉冲的数据。
说明：
1.	每个编码中一定含有E即编码脉冲序号。
2.	每个编码中最多含9个通道数据，编号从0开始，依次对应ABCDEFGHI。
3.	每个编码中含有B1（第一B显点）。当第二B显点有数据时含B2
4.	作业参数和控制参数，有变化时才会记录
5.	关于x、y坐标的说明：x、y坐标是相对于本次脉冲反射点位置的水平和垂直偏移量。
每种数据类型具体的JSON表示方法详见事例部分。
2.1 间隔编码
B显数据是探伤仪移动等距离间隔生成的。此间隔对应《双轨式钢轨超声波探伤仪暂行技术条件》中，6.4.6要求的“应保证在最高持续检测速度下，每个探头（晶片）超声脉冲反射距离间隔不大于3mm”，和7.3.5要求的“在15km/h最高检测速度下，每个探头（晶片）超声脉冲反射距离间隔不大于3mm，即在双轨探伤仪沿钢轨纵向移动3mm的时间内，超声仪器所有通道均至少工作一次。”
 
对每次间隔进行编码，再将其他事件与一系列间隔编码根据先后顺序记录，是整个交换文件的总体结构，示意图如下：
 
图2-1 文件结构示意图
一次间隔编码事件包括键名E和编码。一个文件起始编码为1，之后B显生成都计数累积。
例如第100个间隔编码，用JSON格式表示为：
{"E":100}
2.2 第一B显点
（解释：因为B显图像是由A显信号转换而来，并且探伤采用反射式报警，所以A显信号分析多针对超过报警阈值的第一根最高波，只有在孔裂等端角反射的时候才分析双波信号，所以对于一条A显信号最多只分析两根超过报警阈值的信号，与之对应的B显点最多记录两个。）
B显图像是由A显波形转换而来，A显波形在大闸门内超过大闸门阈值（反射报警阈值）的信号视为反射报警信号。在A显中，从左至右第一个反射报警信号的最高点或者其上升沿与阈值线交点对应的B显点定义为第一B显点，如下图所示。由于报警信号上升沿的陡峭特性，可将最高点深度等同于上升沿与阈值线交点深度。如果报警信号是饱和状态，则其最高点深度为达到饱和状态的第一个点的深度。
 
图2-2 B显点对应A显波形位置
以报警信号最高点为例，一次第一B显点事件对应一个B显点，具体包括键名B1、通道号、深度值、幅度值。
由于每个厂家对通道的编号方法不同，在此交换格式中，将通道编号与角度、射向、股别（车别）配置挂钩，通道编号规则为如下表：

深度值、幅度值如下图所示。深度值数值范围为0~500，单位为mm。幅度值范围为0~100，单位%。

例如前外70°通道存在一个深度为62mm幅度为100%的报警信号，用JSON格式表示为：
{"B1":[1.0,62.0,100.0,16.61,14.57]}

2.3 第二B显点
有些特殊伤损会在A显中产生双波报警信号，例如螺孔孔裂，此时如果将第二根回波也转换成B显，会增强伤损显示效果，因此有必要记录下来同一个间隔编码下的第二个报警信号。不同报警信号区分标准是之间波形低于穿透报警阈值，如下图所示。
 
图2-4 双波报警信号示意图
第二报警信号对应的B显点定义为第二B显点，其深度值与幅度值分析方法同第一B显点。深度值数值范围为0~1000，单位为mm。幅度值范围为0~100，单位为%，如果原始记录中无幅度值，则视信号幅度为100%。
例如前直37°通道存在深度为83mm幅度为100%的第一报警信号，同时存在深度为150mm幅度100%的第二报警信号，用JSON格式表示为：
{"B1":[6.0,83.0,100.0,133.73,80.95]，"B2":[6.0,150.0,100.0,148.85,146.3]}
如无第二报警信号，则不转换此事件。
