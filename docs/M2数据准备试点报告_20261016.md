## 2. 换算链（最终版）

```
x_px（某 Step 图内）
   └─[步进不变式]→ K = x − N（mode M） 或 x + N（mode P，由录制行进方向决定）
        └─[− D]（每录制一个标定常数）→ E（数据 E 轴）
             └─[− BeamOffset[ch]]（从 JSON 配置读，逐录制不同）→ encoding
                  └─[− encoding_min]→ CSV 行号（*_hdc.csv / *_label.csv）
```

## 3. 标定方法与三个坑的解法（本次试点最重要产出）

**指纹**：标注文件里每条螺孔/裂纹都含一段 ch6（37°）主轨迹（E 坐标）；
图片侧同一位置有对应的**绿标记**（K 坐标）。两者做差值直方图即得 D。

| 坑 | 现象 | 解法 |
|---|---|---|
| ① 模式等价 | 单步窗口内 K=x−N 与 K=x+N 完全等价（差常数被 D 吸收） | 必须**跨步**区分：拿锚点查询图在相邻 Step 找孪生命中，Δx 与 ΔN 同号=M、异号=P |
| ② 同构接头重复 | 6/6 拟合有 **14+ 个解**（210201 实测，各接头布局几乎相同） | 两级裁决：候选必须使"片段 K 窗口覆盖锚点 K"→ 再用**锚点裁片自身的绿标记**交叉验证（唯一胜出 D=−9085） |
| ③ 标记类偏移 | 蓝标记相对绿标记有 ~18px 系统偏移，混用会让密集区就近匹配串位 | 标定**只用绿标记**（6/6 残差 ≤2px） |

**防呆铁律**：标定流程内建"片段窗口必须覆盖锚点 K"的一致性检查，不通过即报警
（200922 首轮曾拟合出远端同构接头的假解 C=635266，被此检查拦下）。
