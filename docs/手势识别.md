# EMG手势识别程序详解
## 1. 程序概述
这是一个基于超维计算（Hyperdimensional Computing, HDC）的EMG（肌电图）手势识别程序，使用PyTorch和torchhd库实现。程序从EMGHandGestures数据集加载数据，训练HDC模型，然后测试模型的识别准确率。

## 2. 输入数据格式
### 数据集来源
程序使用 EMGHandGestures 数据集，这是一个包含肌电图信号的手势识别数据集。

### 原始数据格式
- 形状 ： [256, 4] (256个时间点 × 4个EMG传感器通道)
- 数据类型 ：浮点数，范围约0-0.25
- 四列含义 ：
  - 第1列: EMG传感器1的信号值
  - 第2列: EMG传感器2的信号值
  - 第3列: EMG传感器3的信号值
  - 第4列: EMG传感器4的信号值
### 数据预处理
程序对原始数据进行了以下预处理：

1. 降采样 ：
   
   ```
   DOWNSAMPLE = 5
   SUBSAMPLES = torch.arange(0, 
   WINDOW, int(WINDOW / DOWNSAMPLE))
   def transform(x):
       return x[SUBSAMPLES]
   ```
   - 将256个时间点降采样到约51个点
   - 减少计算量，提高模型训练效率
2. 数据划分 ：
   
   ```
   train_size = int(len(ds) * 0.7)
   test_size = len(ds) - train_size
   train_ds, test_ds = data.
   random_split(ds, [train_size, 
   test_size])
   ```
   - 70%训练集，30%测试集
   - 随机划分，确保训练和测试数据分布均匀
### 模型输入格式
- 形状 ： [batch_size, timestamps, channels]
- 示例 ： [1, 51, 4] (1个样本 × 51个时间点 × 4个通道)
- 数据类型 ：PyTorch张量，浮点数
## 3. 识别结果的数据格式
### 模型输出
- 形状 ： [batch_size, num_classes]
- 数据类型 ：PyTorch张量，浮点数
- 含义 ：每个类别对应的相似度得分
- 示例 ： [0.2, 0.8, 0.1, 0.3, 0.5] (5个类别，第2个类别得分最高)
### 最终识别结果
- 形状 ： [batch_size]
- 数据类型 ：PyTorch张量，整数
- 含义 ：预测的手势类别索引
- 示例 ： [1] (预测为第2个手势类别)
### 评估结果
- 准确率 ：百分比值，表示模型正确识别的样本比例
- 示例 ： 85.5%
## 4. 函数和参数详解
### 4.1 配置参数
参数名 类型 含义 值 DIMENSIONS 整数 超向量维度 10000 NUM_LEVELS 整数 水平嵌入的级别数 21 BATCH_SIZE 整数 批处理大小 1 WINDOW 整数 每个样本包含的时间点数量 256 N_GRAM_SIZE 整数 用于捕获时序关系的N-gram大小 4 DOWNSAMPLE 整数 降采样因子 5 SUBSAMPLES 张量 用于降采样的时间点索引 生成的索引数组

### 4.2 Encoder类
作用 ：将EMG信号转换为超维向量
 __init__方法
```
def __init__(self, out_features, 
timestamps, channels):
    super(Encoder, self).__init__()
    self.channels = embeddings.
    Random(channels, out_features)
    self.signals = embeddings.Level
    (NUM_LEVELS, out_features, 
    high=20)
```
参数 类型 含义 out_features 整数 输出超向量的维度 timestamps 整数 输入时序数据的时间点数量 channels 整数 输入数据的通道数量

组件 ：

- self.channels ：通道嵌入层，将每个通道映射到超维空间
- self.signals ：信号嵌入层，将连续信号值映射到超维空间 forward方法
```
def forward(self, input: torch.
Tensor) -> torch.Tensor:
    signal = self.signals(input)
    samples = torchhd.bind(signal, 
    self.channels.weight.unsqueeze
    (0))
    samples = torchhd.multiset
    (samples)
    sample_hv = torchhd.ngrams
    (samples, n=N_GRAM_SIZE)
    return torchhd.hard_quantize
    (sample_hv)
```
步骤 操作 函数/方法 含义 1 信号嵌入 self.signals(input) 将连续EMG信号值映射到超维空间 2 通道绑定 torchhd.bind(signal, self.channels.weight.unsqueeze(0)) 将通道信息与信号嵌入结合 3 多集聚合 torchhd.multiset(samples) 聚合多个时间点的超向量 4 N-gram处理 torchhd.ngrams(samples, n=N_GRAM_SIZE) 捕获序列数据的时序关系 5 硬量化 torchhd.hard_quantize(sample_hv) 将超维向量转换为二进制向量

### 4.3 experiment函数
作用 ：执行完整的训练和测试实验

```
def experiment(subjects=[0]):
    # 加载数据集
    ds = EMGHandGestures("../data", 
    download=True, 
    subjects=subjects, 
    transform=transform)
    
    # 划分训练集和测试集
    train_size = int(len(ds) * 0.7)
    test_size = len(ds) - train_size
    train_ds, test_ds = data.
    random_split(ds, [train_size, 
    test_size])
    
    # 创建数据加载器
    train_ld = data.DataLoader
    (train_ds, 
    batch_size=BATCH_SIZE, 
    shuffle=True)
    test_ld = data.DataLoader
    (test_ds, 
    batch_size=BATCH_SIZE, 
    shuffle=False)
    
    # 初始化编码器
    encode = Encoder(DIMENSIONS, ds
    [0][0].size(-2), ds[0][0].size
    (-1))
    encode = encode.to(device)
    
    # 初始化模型
    num_classes = len(ds.classes)
    model = Centroid(DIMENSIONS, 
    num_classes)
    model = model.to(device)
    
    # 训练模型
    with torch.no_grad():
        for samples, targets in tqdm
        (train_ld, desc="Training"):
            samples = samples.to
            (device)
            targets = targets.to
            (device)
            sample_hv = encode
            (samples)
            model.add(sample_hv, 
            targets)
    
    # 测试模型
    accuracy = torchmetrics.Accuracy
    ("multiclass", 
    num_classes=num_classes)
    with torch.no_grad():
        model.normalize()
        for samples, targets in tqdm
        (test_ld, desc="Testing"):
            samples = samples.to
            (device)
            sample_hv = encode
            (samples)
            output = model
            (sample_hv, dot=True)
            accuracy.update(output.
            cpu(), targets)
    print(f"Testing accuracy of 
    {(accuracy.compute().item() * 
    100):.3f}%")
```
参数 类型 含义 subjects 列表 要使用的受试者ID列表，默认仅使用受试者0

关键步骤 ：

1. 数据集加载 ：
   
   - EMGHandGestures ：加载EMG手势数据集
   - download=True ：如果数据集不存在则自动下载
   - transform=transform ：应用数据预处理
2. 模型初始化 ：
   
   - Encoder ：创建超维编码器
   - Centroid ：创建HDC质心模型，用于存储类别超向量
3. 训练过程 ：
   
   - 遍历训练数据，将每个样本转换为超维向量
   - 使用 model.add(sample_hv, targets) 将超向量添加到对应类别的质心中
4. 测试过程 ：
   
   - model.normalize() ：归一化类别超向量
   - 遍历测试数据，生成超维向量
   - model(sample_hv, dot=True) ：计算超向量与类别质心的相似度
   - accuracy.update(output.cpu(), targets) ：更新准确率统计
   - accuracy.compute() ：计算最终准确率
### 4.4 主程序
```
# 为每个受试者创建一个模型
for i in range(5):
    experiment([i])
```
作用 ：遍历前5个受试者，为每个受试者单独训练和测试模型，评估模型在不同受试者上的泛化能力。

## 5. 识别结果数据格式
### 模型输出
- 形状 ： [batch_size, num_classes]
- 示例 ：对于5个手势类别，输出可能为 [0.2, 0.8, 0.1, 0.3, 0.5]
- 含义 ：每个值表示输入样本与对应类别质心的相似度（点积值）
### 最终预测结果
- 形状 ： [batch_size]
- 示例 ： [1]
- 含义 ：预测的手势类别索引（从0开始）
- 对应关系 ：
  - 0: "Closed hand" (握拳)
  - 1: "Open hand" (张开手掌)
  - 2: "Two-finger pinch" (两指捏合)
  - 3: "Point index" (伸出食指)
  - 4: "Rest position" (休息姿势)
### 评估结果
- 格式 ：百分比值
- 示例 ： Testing accuracy of 85.500%
- 含义 ：模型在测试集上的正确识别率

## 7. 关键技术点
1. 超维计算 ：使用高维向量表示数据，具有抗噪声、低功耗等优点
2. 通道嵌入 ：将不同传感器通道的信息映射到超维空间
3. 时序建模 ：使用N-gram捕获EMG信号的时序关系
4. 质心模型 ：将同类样本的超向量聚合为类别质心
5. 相似度计算 ：使用点积计算超向量之间的相似度
