# 钢轨探伤B显数据JSON解析与可视化工具需求文档

## 1. 项目概述

### 1.1 项目背景
该工具用于解析和可视化钢轨探伤B显数据，根据《钢轨探伤B显数据JSON数据交换格式》规范编写，支持多种JSON格式输入，生成直观的B显图像和数据摘要。

### 1.2 项目目标
- 解析不同格式的钢轨探伤B显数据JSON文件
- 可视化B显数据，支持交互式查看
- 提供数据摘要和统计信息
- 支持多种参数配置和通道管理

## 2. 功能需求

### 2.1 数据解析功能
- **支持多种JSON格式**：
  - JSON Lines格式（每行一个JSON对象）
  - JSON数组格式（整个文件是一个数组）
  - 单行JSON数组格式

- **事件类型支持**：
  - E: 间隔编码（横轴坐标）
  - B1/B2: 第一/第二B显点 [通道号, 深度, 幅度]
  - 系统参数: Sensitivity, GateStart/End, GateLevel等
  - 作业信息: Bureau, Division, Operator, DeviceNum等
  - 其他: Comment, Back, Remark

### 2.2 数据存储功能
- **事件数据存储**：按顺序存储所有事件
- **B显数据存储**：
  - B1点数据：编码值、通道、深度、幅度
  - B2点数据：编码值、通道、深度、幅度
- **系统参数存储**：
  - 灵敏度、闸门参数、探测范围、声束角度等
- **作业信息存储**：
  - 路局、站段、车间、工区、班组等
  - 执机人、机号、机型、作业日期、时间等
  - 里程、上下行、股别、速度等

### 2.3 数据处理功能
- **深度值修正**：深度值 × cos(通道角度)
- **横向移动距离修正**：编码值 + (深度值 × sin(通道角度))/3
- **灵敏度过滤**：过滤掉幅度低于灵敏度的点
- **拼孔值应用**：编码值 - int(拼孔值 / 3)

### 2.4 可视化功能
- **B显点绘制**：
  - 根据通道分配特定颜色
  - 根据幅度设置点的大小
  - 支持B1（圆点）和B2（三角形）点区分
- **信息面板**：
  - 作业信息显示
  - 通道统计
  - 通道配置
  - 灵敏度表
  - 闸门参数
  - 探测范围
  - 声束角度
  - 拼孔值
- **交互功能**：
  - 支持缩放
  - 支持保存图像
  - 支持命令行参数控制是否显示

### 2.5 命令行功能
- **自动查找JSON文件**：当未指定文件时，从当前目录查找第一个JSON文件
- **输出图像文件**：支持指定输出图像文件名
- **非交互式模式**：支持--no-show参数，只保存图像不显示

## 3. 新增需求

### 3.1 窗口上位机功能
- **图形用户界面**：将命令行工具升级为窗口上位机
- **X轴可拖动条**：在界面底部添加可拖动的X轴滑动条，用于控制显示的编码值范围
- **实时更新**：拖动滑动条时，实时更新显示的B显图像
- **缩放功能**：支持鼠标滚轮缩放和窗口大小调整
- **菜单栏**：包含文件、视图、工具、帮助等菜单

### 3.2 数据标注功能
- **类型选择**：提供结构类型和伤损类型选择界面
  - 伤损类型：轨头外侧核伤、轨头中心核伤、轨头内侧核伤等
  - 结构类型：接头、螺孔、导线孔、焊缝等
- **点选择功能**：
  - 支持框选多个点
  - 支持单击选择单个点
  - 支持按住Shift键多选
  - 支持取消选择
- **标注数据生成**：
  - 将选中的点按照编码值排序
  - 生成JSON格式的标注数据
  - 示例：用E101 B1 E102 B1 E103 B1表示为螺孔1
  - 标注数据包含：类型、编码值范围、通道信息、点数据等
- **标注数据保存**：
  - 支持保存标注数据到JSON文件
  - 支持加载已有标注数据
  - 支持编辑和删除已有标注

## 4. 数据格式

### 4.1 输入JSON格式
```json
{
  "E": 123,
  "B1": [0, 100, 80],
  "B2": [1, 150, 70],
  "Sensitivity": [0, 30, 1, 35],
  "Bureau": "北京铁路局",
  "Operator": "张三"
}
```

### 4.2 标注数据JSON格式
```json
{
  "annotations": [
    {
      "id": "1",
      "type": "螺孔",
      "subtype": "1",
      "points": [
        {"E": 101, "B": "B1", "channel": 0, "depth": 100, "amplitude": 80},
        {"E": 102, "B": "B1", "channel": 0, "depth": 105, "amplitude": 85},
        {"E": 103, "B": "B1", "channel": 0, "depth": 110, "amplitude": 90}
      ],
      "start_E": 101,
      "end_E": 103,
      "channels": [0],
      "timestamp": "2026-01-08T10:00:00"
    }
  ]
}
```

### 4.3 数据结构
- **B显点数据**：[通道号, 深度, 幅度, ...]
- **系统参数**：[通道号, 值, 通道号, 值, ...]
- **作业信息**：键值对格式

## 6. 技术实现

### 6.1 技术栈
- Python 3.x
- JSON库
- matplotlib（可视化）
- PyQt5或Tkinter（GUI框架）
- 数学库（三角函数计算）

### 6.2 关键算法
- **深度值修正**：depth = original_depth × cos(angle)
- **横向移动距离修正**：e = original_e - int(beam_offset/3) + int((depth × sin(angle))/3)
- **幅度过滤**：只显示幅度 >= 灵敏度的点

## 7. 使用说明

### 7.1 命令行用法
```
python parse_flaw_detection_json.py <json文件路径> [输出图像文件] [--no-show]
```

### 7.2 窗口上位机用法
1. 启动程序后，点击"文件"菜单，选择"打开"，导入JSON文件
2. 在主界面查看B显图像和信息面板
3. 使用底部的X轴滑动条调整显示的编码值范围
4. 点击"标注"菜单，选择"开始标注"
5. 从类型列表中选择要标注的类型
6. 在B显图像上选择要标注的点
7. 点击"保存标注"，将标注数据保存为JSON文件

### 7.3 示例
```
python parse_flaw_detection_json.py 123.json
python parse_flaw_detection_json.py 123.json output.png
python parse_flaw_detection_json.py 123.json --no-show
```

### 7.4 输出
- **数据摘要**：总事件数、B1/B2点数、活动通道等
- **可视化图像**：B显点分布图和右侧信息面板
- **标注数据**：JSON格式的标注数据

## 12. 附录

### 12.1 术语定义
- **B显**：B型显示，将探测深度和回波幅度以二维图像形式显示
- **间隔编码**：横轴坐标，表示探头移动的距离
- **拼孔值**：通道X坐标的偏置参数，用于调整不同通道的起点位置
- **声束角度**：超声波探头的发射角度
- **灵敏度**：报警阈值，用于过滤低幅度信号
